# Gallery

`samples/Cupertino.Gallery` is the live companion to the documentation. It includes the main states, customized examples, and edge cases for every themed and Cupertino-specific control.

<img src="../images/gallery-home.png"
     alt="Cupertino.Gallery running in the iOS 26.2 Simulator"
     width="420" />

## Desktop

```bash
dotnet run --project samples/Cupertino.Gallery.Desktop
```

## Mobile

Platform heads are available at:

- `samples/Cupertino.Gallery.iOS`
- `samples/Cupertino.Gallery.Android`

Use the iOS 26.2 Simulator as the primary visual reference when comparing metrics and behavior. Desktop and Android should preserve the same design language while remaining usable with their native input methods.

The source for each gallery page lives in [`samples/Cupertino.Gallery/Pages`](https://github.com/jsuarezruiz/Cupertino.Avalonia/tree/main/samples/Cupertino.Gallery/Pages).
